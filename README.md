# Lingotype

Простой тренажёр слепой печати и английского. Статические HTML, CSS и JavaScript, без фреймворков, зависимостей, сервера приложения и аккаунтов. Подходит для GitHub Pages, в том числе для адреса с именем репозитория в пути.

## Запуск

Нужен Node.js 22 или новее. Устанавливать зависимости не требуется.

```sh
npm start
```

Открой `http://127.0.0.1:4173`. Двойной клик по `index.html` не подходит: браузер ограничивает ES-модули и загрузку JSON на `file://`.

```sh
npm run validate # проверить коллекцию текстов
npm test         # проверить печать, подсчёты, прогресс и повторения
npm run build    # собрать готовые статические файлы в dist/
```

## GitHub Pages

Адрес проекта: **https://meldxkviel.github.io/lingotype/**.

Публикация настроена через `.github/workflows/pages.yml`: каждый push в `main` запускает тесты, собирает `dist/` и публикует его в GitHub Pages. Повторный запуск доступен в **Actions → Publish Lingotype → Run workflow**. В **Settings → Pages** источник публикации — **GitHub Actions**.

Файл `.nojekyll` уже добавлен. Все пути относительные; менять имя репозитория в коде не нужно. Для другого статического хостинга достаточно содержимого `dist/` после `npm run build`.

[Официальная инструкция GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site).

## Что внутри

- Оригинальные короткие тексты, 8 тем (включая IT и кино), ориентировочные уровни A1–C2. Материалы есть для каждого сочетания темы и уровня. Текущее количество текстов и выражений показывает `npm run validate`.
- Точная посимвольная печать: ошибка требует Backspace; все попытки остаются в расчёте точности.
- Печать по основному тексту без отдельного видимого поля. Автофокус при открытии, смене текста и закрытии разбора; скрытый нативный приёмник ввода поддерживает экранную клавиатуру и доступное имя.
- Лёгкий щелчок настоящей печатной машинки: локальная запись под CC0, укороченная и смягчённая, с сохраняющимся выключателем. Звук включается после первого действия пользователя. [Источник и лицензия](assets/audio/README.md).
- Экранная QWERTY-клавиатура с пятью цветными зонами пальцев, легендой и анимацией нажатий; подсказка пальца, противоположный Shift для заглавных букв, предупреждение о русской раскладке.
- Перевод под текстом с сохраняющимся переключателем.
- Кликабельные выражения: смысл, объяснение, пример и прямая ссылка на YouGlish. Наличие конкретных видеопримеров и ограничения внешнего сервиса зависят от YouGlish.
- Копилка до 20 выражений. Следующий текст появляется сразу; результат и новые награды показываются коротким уведомлением без кнопок и остановок.
- Случайные тексты в практике: первый текст, «Другой текст» и переход после завершения выбираются случайно в пределах темы и уровня. В течение занятия тексты не повторяются, пока не закончится текущий круг; на стыке кругов один текст не выпадает дважды подряд, если есть другие. После перезагрузки недавние завершённые тексты из сохранённой очереди пропускаются, пока есть другие. Повторения доступны в отдельном режиме «Повторение».
- Повторения через 1, 3, 7, 14 дней. Точность ниже 95% возвращает текст на следующий день. Досрочные повторы не продвигают интервал. Интервалы — простой продуктовый выбор, а не универсальная научная норма.
- Цель 3 текста в день, серия по локальным календарным дням, 6 небольших наград.
- Прогресс хранится только в cookie `lingotype_v1`, в пределах пути приложения. Без localStorage, аналитики и отправки результатов на сервер.
- Адаптивная вёрстка, нативные диалоги, управление клавиатурой, фокус, подписи, reduced-motion и экранные уведомления.

## Добавление материалов с минимумом контекста

Прочитай **[content/README.md](content/README.md)** и файл нужной темы. Больше знать проект не требуется. Машиночитаемая схема: `content/lesson.schema.json`. Валидатор проверяет ID, длину и символы текста, точное совпадение и непересечение выражений.

## Прогресс и расчёты

Cookie живёт до года с последнего сохранения. Сохраняются общие счётчики, награды, настройки, до 20 ID выражений и очередь из последних 14 уникальных текстов. Размер значения ограничен 3 400 байтами ASCII; при переполнении сокращается очередь повторений. Если cookies отключены, приложение предупреждает и работает с временным состоянием в памяти. Сброс прогресса доступен через «Прогресс в этом браузере».

Скорость: правильно напечатанные символы / 5 / минуты активного ввода. Точность: верные попытки / все принятые попытки. Ошибка остаётся в статистике после исправления. Время до первой клавиши, время вне поля и чтение разбора не учитываются; бездействие ограничено 15 секундами. На коротких текстах скорость приблизительна. Рекорд засчитывается только при точности от 95% и продолжительности от 10 секунд. Пропуск и незавершённый текст наград не дают.

Это лёгкое локальное приложение: без синхронизации, восстановления после очистки cookies и защиты от ручной подмены счётчиков. Открывай одну вкладку для практики — параллельные вкладки могут перезаписывать cookie. Стили используют Google Fonts с системными запасными шрифтами; без доступа к Google приложение продолжает работать.

## Учебные принципы

Приоритет точности опирается на [рекомендации Typing.com](https://www.typing.com/blog/typing-accuracy/). Скрываемый перевод и копилка без сразу видимого значения позволяют по желанию практиковать [активное вспоминание](https://www.retrievalpractice.org/retrievalpractice/), а повторения в разные дни используют [распределённую практику](https://www.retrievalpractice.org/spacing/). Обязательных вопросов и экранов завершения нет. Короткие сессии и цель в 3 текста — мягкая настройка приложения. Копирование текста само по себе не заменяет разговорную практику: полезно проговаривать выражения и составлять свои примеры.

```text
src/app.js               взаимодействия и отображение
src/core.js              печать, статистика и повторения
src/storage.js           ограниченное cookie-хранилище
src/icons.js             небольшие интерфейсные SVG-иконки
content/                 редактируемые тексты и инструкция
scripts/                 локальный сервер, проверка и сборка
tests/                   тесты логики
```
