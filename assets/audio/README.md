# Typewriter key

`typewriter-key.wav` is an adapted excerpt from **typewriter1.wav**, recorded by **Cassie-OrbitGames**.

- Source: https://opengameart.org/content/typewriter-sounds
- Original file: https://opengameart.org/sites/default/files/typewriter1.wav
- License: [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/), as stated by the author on the source page.
- Retrieved: 2026-09-08.

Adaptations: isolated the first 160 ms keystroke, removed the leading silence, applied a low-pass filter, softened the attack and release, and normalized the peak to 0.6. Playback volume is reduced further in the app. The sample ships with the static site; no external audio requests are made at runtime.
