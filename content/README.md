# Добавление текстов: читать только этот файл и нужную тему

Приложение автоматически читает темы из `catalog.json`. Для добавления текста **не нужно читать или менять исходный код**.

1. Выбери файл темы: `everyday.json`, `people.json`, `work.json`, `travel.json`, `leisure.json`, `learning.json`, `it.json` или `cinema.json`.
2. Добавь объект в конец массива. Скопируй пример ниже.
3. Выполни `npm run validate` в корне проекта. Исправь найденные ошибки.

```json
{
  "id": "day-10",
  "level": "A2",
  "title": "Небольшая помощь",
  "text": "Could you give me a hand with these bags? They are a little heavy.",
  "translation": "Не мог бы ты помочь мне с этими сумками? Они немного тяжёлые.",
  "phrases": [
    {
      "id": "give-me-a-hand",
      "text": "give me a hand",
      "meaning": "помочь мне",
      "note": "Give someone a hand — помочь кому-либо. Не означает буквально отдать руку.",
      "example": "Can you give me a hand with the boxes?"
    }
  ]
}
```

Правила:

- Все ID уникальны по всей коллекции, до 48 символов: строчные латинские буквы, цифры и дефис. При редактировании сохраняй существующие ID: на них ссылаются cookies. Для повторного выражения в новом контексте используй новый ID (например, `give-me-a-hand-work`). Валидатор найдёт случайные дубли.
- `level`: `A1`, `A2`, `B1`, `B2`, `C1` или `C2` — ориентировочная сложность, не официальная сертификация CEFR. A1: простые фразы и частотные слова; A2: бытовые ситуации; B1: связные мысли и разговорные выражения; B2: аргументация, причинно-следственные связи и сложные предложения; C1: инверсии, уступительные конструкции и точные оттенки смысла; C2: подразумеваемая оценка, неоднозначность, идиоматика и абстрактное рассуждение. Не повышай уровень только из-за IT-терминов или редких слов. Короткий текст не проверяет владение уровнем целиком.
- `text`: 20–240 символов, обычно 1–2 естественных предложения. Только печатные ASCII-символы: обычные `'` и `"`, без типографских кавычек, длинных тире, переносов строк и двойных пробелов. Никакого HTML.
- `translation`: естественный русский перевод всего текста, с сохранением смысла выражений.
- `phrases`: 1–3 полезных выражения. `text` внутри фразы должен **точно, с тем же регистром** встречаться один раз в тексте, целыми словами. Выражения не пересекаются.
- `meaning`: короткий перевод; `note`: понятное объяснение, контекст или отличие от похожей конструкции; `example`: отдельный естественный пример на английском.
- Выражения открываются по желанию пользователя. Обязательных вопросов между текстами нет: печать продолжается автоматически.
- Ссылку YouGlish добавлять не нужно: приложение собирает её из текста выражения автоматически.
- Пиши оригинальные предложения, без длинных цитат из книг и фильмов. Проверяй английский и русский смысл. Автоматическая проверка контролирует структуру, но не заменяет языковую редактуру.

Новая тема: создай такой же JSON-массив и добавь в `catalog.json` запись `{"id":"food","title":"Еда","file":"food.json"}`. Затем запусти проверку. Чтобы контент попал в `dist`, выполни `npm run build`.

Короткое поручение будущему агенту: «Прочитай `content/README.md` и `content/travel.json`. Добавь 6 оригинальных текстов A2 про путешествия. Сохрани старые ID. Выполни `npm run validate`».
